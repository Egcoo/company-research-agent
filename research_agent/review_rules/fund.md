# 基金报告判卷标准

按 inputs.fund_type 和所选份额审阅，优先指出会改变结论的错误。

1. 对象和历史：基金代码、名称、份额、成立/增设日期一致。后增设 C 类不能借用 A 类历史补足三年；母基金历史仅可明确标注为背景。
2. 数字与口径：净值日期、报告期、币种、单位、百分比与百分点正确；区分单位净值和含分红的财富序列、收益与最大回撤。对照 fund_data 和所选份额的 retained_nav 核对表述；原始序列不能代替程序独立复算。分红近似、不可得指标应保留说明。
3. 比较：最新净值与官方披露只能按相同期间比较。官方复合基准、目标 ETF、普通对照产品、基金实际配置分别处理。对照收益差不是经理 alpha，基准权重不是实际配置。没有可靠基准日序列时不得编造独立跟踪误差或信息比率。
4. 费用：按份额、来源日期和适用条件核实；冲突费率、申购折扣、持有期未知时，不能给出确定的 A/C 优劣。净值已扣的运作费用不能重复扣，三项费率之和不自动等于全部成本。
5. 依据与缺口：关键判断必须有 sources 原文支持。笔记、搜索线索、链接存在和模型自己写出的结论均不构成独立证据。买入/观察阈值、替代品成本优势、经理持续能力和业绩归因需要来源或明确推导；区分事实、经理观点、估计和推断。
6. 子类型：被动/ETF 联接核对指数暴露与目标 ETF；增强指数核对增强过程与官方跟踪风险；混合基金区分合同范围和实际组合，单次持仓不能证明风格稳定；债券基金核对利率、信用、杠杆和流动性证据，单券占比不等于发行人集中度。利率上升/下降情景不能混用百分比，敏感性反推的数值不能冒充官方久期或再次重复乘杠杆。

优先检查核心结论、风险和执行条件，以及正文与程序绩效/费用表是否矛盾。资料不足且报告如实披露，不扣成事实错误。不要强行套用股票收入、EPS 或 DCF。
