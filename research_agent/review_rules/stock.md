# 股票报告判卷标准

围绕 inputs 指定的公司、研究问题和信息截止日，优先指出会改变结论的错误。

1. 对象和时点：公司、股票代码、财年、报告期和估值价格日期对应；不得使用任务截止日之后的价格或消息，未确认交易日不能编造周末解释。
2. 历史数字：对照 sources 核实收入、利润、现金流、资产负债及股数，注明币种和数量级。全年、季度、上半年累计不可混用；实际披露、调整后口径、假设和预测分开。
3. 预测桥接：收入驱动、毛利率、费用、税、股数到 EPS 的假设应闭合，利润到现金流的转换应说明。中值不等于指引下限，缺少输入不能当成已完成的计算。
4. 估值：DCF 应给出逐期现金流、折现及终值假设、净现金/债务与每股转换，使读者能够复算；仅有估值结论或 PE/FCF 收益率不能证明 DCF 已完成。资料不足时指出缺口，不替作者补造假设或假装用程序审计。
5. 依据：关键公司、行业、管理层和风险判断应受 sources 原文支持。笔记与搜索标题/摘要只是线索，URL 读过不代表该网页支持每句话。区分管理层观点、研究假设、可核实事实和因果推断。
6. 建议和缺口：买入阈值、催化剂、失效条件应有来源或可解释推导；不要根据少数价格点编造技术位，不把未核实新闻写成确定风险。重要缺口若如实披露，不当成已经编造的事实。

检查结论、财务预测、估值、风险和执行条件是否互相一致。仅使用提供的材料；原始财报未覆盖的事项应标“无法核实”，不能凭模型记忆补全。
